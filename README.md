# Weather-forecast

Weather-forecast — простое учебное приложение на React + Vite для просмотра прогноза погоды (desktop-ориентированное). Проект реализован как тренировочный (study) проект: показывает текущую погоду и краткий прогноз, имеет удобный интерфейс для поиска по городу.

Демо

Живой пример: https://weather-forecast-khaki-three.vercel.app

Если демо перестанет работать — убедитесь, что в package.json и процессе деплоя прописан корректный API-ключ и переменные окружения.

Особенности

Поиск погоды по названию города.

Отображение текущей температуры, влажности, состояния неба, иконки погоды.

Адаптирован под desktop (широкие макеты).

Построено с использованием React и Vite.

------------------------------------------------------------------------------------------------------
Weather-forecast is a simple study project built with React + Vite for viewing weather forecasts (desktop-oriented). It displays the current weather and a short forecast with an easy-to-use city search.

Demo

Live example: https://weather-forecast-khaki-three.vercel.app

If the demo doesn’t work, make sure the package.json and deployment settings include a valid API key and environment variables.

Features

Search weather by city name.

Displays current temperature, humidity, sky conditions, and weather icons.

Optimized for desktop layouts.

Built with React and Vite.

Tech stack

React

Vite

JavaScript (ES6+)

CSS (or SCSS)

Weather API (e.g., OpenWeatherMap or another provider; check the code for details)

API погоды (поддерживаемый провайдер — OpenWeatherMap или аналог; в проекте может использоваться другой — проверь код)
